Three projects from my role as a technical data analyst on conversational AI products. Client names and data stay confidential.

01

Making the case for LLM routing

68% → 85% reported routing accuracy in a client comparison of intent-based and LLM routing
  1. Real customer conversations
  2. Dialogflow intents vs. an LLM router
  3. Accuracy compared side by side
  4. A client-ready recommendation
The problem
Intent-based chatbot routing in Dialogflow kept sending customers to the wrong place, especially when one message asked for several things at once.
What I did
Compared intent matching with LLM-based routing on real conversations, then turned the results into a clear, client-ready analysis.
The outcome
The LLM routed noticeably more accurately, and several clients moved their solutions to LLM routing.
  • Dialogflow
  • LLMs
  • Conversation analytics
02

Finding structure in thousands of conversations

80–85% estimated coverage of general intents, starting from about 150 sampled transcripts
  1. ~150 sampled transcripts
  2. An LLM drafts the intent taxonomy
  3. Embeddings match every conversation
  4. An intent map at full scale
The problem
Transcripts were too long to hand to an LLM whole. Details in the middle got lost, so summaries couldn’t be trusted.
What I did
Had an LLM draft an intent taxonomy from about 150 sampled transcripts, then used embedding models to match every remaining conversation against it.
The outcome
A map of what customers actually ask for, built at scale without asking an LLM to read every word.
  • Python
  • LLMs
  • Embeddings
  • Taxonomy design
03

A weekly pipeline that runs itself

Every Monday scheduled on Google Cloud, with no one pressing a button
  1. Cloud Scheduler fires on Monday
  2. A Python job wakes on Cloud Run
  3. Three chained SOQL lookups
  4. Customer details, ready for the team
The problem
Client teams needed customer details pieced together from Salesforce on a recurring basis, which took several dependent lookups each time.
What I did
Wrote a Python job that chains three SOQL queries against a client-supplied list, deployed it on Cloud Run and scheduled it with Cloud Scheduler.
The outcome
A recurring request became a scheduled job. I investigated failures through Cloud Run logs, including timeouts caused by long-running queries.
  • Python
  • Salesforce API
  • Cloud Run
  • Cloud Scheduler
